# AI Translate

Плагин для Discord, который переводит ваши сообщения выбранной вами моделью ИИ
и не причёсывает то, как вы пишете.

Ваши сообщения переводятся перед отправкой, отдельно в каждом чате. Входящие
переводятся тогда, когда вы попросите, через меню по правому клику.

## Зачем ещё один переводчик

Машинный перевод сделан для прозы. Переписка не проза. Она идёт строчными
буквами и недоговорёнными фразами, держится на каомодзи, и отсутствие точки в
ней что-то значит. Большинство переводчиков тихо всё это причёсывает, и на
другой стороне получается бланк, написанный кем-то другим.

Этот сделан вокруг того, чтобы ничего не трогать. Он не поставит точку, которую
вы не ставили, не сделает заглавной букву, которую вы оставили строчной,
оставит переносы строк там, где вы их поставили, и знает, что смайлик это лицо,
а не слово, которое надо перевести.

## Что он умеет

Автоперевод включается отдельно для каждого чата, так что он работает только
там, где действительно нужен. Левый клик по кнопке переводчика в поле ввода
открывает панель, правый включает или выключает текущий чат.

Любое входящее сообщение можно перевести через меню по правому клику. Когда и
перевод не помогает, из-за сокращений, словечка, которое используют в одной
стране, или шутки, понятной двоим, **AI Explain** в том же меню называет язык,
расшифровывает сокращения и объясняет, что имелось в виду.

Вместе с запросом уходят несколько последних сообщений беседы, поэтому короткое
«да» или «не вставляется» доходит так, как задумано. Можно закрепить и свой
словарь: слова, которые нельзя переводить, термины с одним фиксированным
переводом, свой грамматический род и то, на «ты» или на «вы» обращаться к
собеседнику.

Отдельное сообщение тоже может сохранить часть себя. Поставьте слово или фразу
между двумя обратными слешами, `\carpe diem\`, и она уйдёт ровно так, как вы её
набрали, без самих слешей; обратный слеш в начале строки оставляет как есть всю
строку. Код в обратных кавычках не переводится никогда.

Под вашими отправленными сообщениями может оставаться оригинал, видимый только
вам, чтобы вы видели, что ушло на самом деле; это выключено, пока вы сами не
включите. Интерфейс говорит на 16 языках и следует языку Discord, пока вы не
выберете другой.

## Провайдеры

Ключ API вы приносите свой, и он остаётся вашим. У плагина нет своего сервера,
и он никогда не видит чужих ключей.

| Провайдер | Бесплатный тариф |
|---|---|
| Groq | есть |
| Google Gemini | есть |
| Z.ai GLM | есть, и работает там, где два предыдущих заблокированы |
| Anthropic Claude | нет |
| Любой API, совместимый с OpenAI | зависит от провайдера |

Вторым можно назначить запасного провайдера. Когда первый перегружен, исчерпал
лимит или отказал, перевод молча уходит через другого.

Запросы уходят из фонового процесса Discord, поэтому ключ не попадает в ту
часть Discord, до которой может дотянуться веб-страница.

## Установка

AI Translate работает внутри Vencord, известного мода для приложения Discord.
Одна команда скачивает Vencord, в который AI Translate уже встроен, это около
мегабайта, и подключает его к Discord. На вашем компьютере ничего не
собирается и ничего больше ставить не нужно. Работает с обычным Discord, PTB и
Canary на Windows, macOS и Linux.

**Windows.** Откройте PowerShell (меню «Пуск», наберите «PowerShell») и
вставьте:

```
irm https://builds.zolatau.com/install.ps1 | iex
```

**macOS и Linux.** Откройте терминал и вставьте:

```
sh -c "$(curl -fsSL https://builds.zolatau.com/install.sh)"
```

Стрелками выберите **Install or update** и нажмите Enter. Когда спросит, какой
Discord подключить, выберите так же тот, которым пользуетесь. На Windows
команда сама закрывает Discord перед подключением. На Linux может понадобиться
пароль: обычно Discord лежит там, куда может писать только администратор.
Потом закройте Discord полностью, в том числе из трея, и запустите снова.

На атомарных системах Linux, таких как Bazzite, Silverblue, Kinoite или
SteamOS, работает та же команда: в систему она ничего не ставит, всё уходит в
`~/.aiTranslate`. Сам Discord должен быть из Flatpak, тогда установщик сам
выдаст этому Flatpak доступ к этим файлам. Discord, вшитый в образ системы
через `rpm-ostree`, подключить обычно нельзя: системные папки там только для
чтения, поставьте версию из Flatpak.

AI Translate уже включён. Откройте **Настройки → Vencord → Plugins →
AI Translate**, выберите провайдера и вставьте свой ключ.

Всё, что скачивает команда, лежит в отдельной папке: `%LOCALAPPDATA%\aiTranslate`
на Windows и `~/.aiTranslate` на macOS и Linux. Подключение к Discord означает,
что его стартовый файл меняется на маленький, который сначала загружает
Vencord, а потом Discord ровно как раньше; вашу учётную запись, настройки и
сообщения это не трогает.

## Обновления

Делать ничего не нужно. AI Translate сам раз в 2 дня ищет новую версию,
скачивает её в фоне и показывает уведомление; нажмите на него, и Discord
перезапустится уже с новой версией. Если не нажимать, обновление просто
применится при следующем запуске Discord. **Проверить обновления** внизу
настроек плагина делает то же самое сразу.

Каждая новая версия несёт и свежий Vencord, так что его собственные исправления
приходят тем же путём. На Windows и Linux подключение переживает и обновления
самого Discord. Если AI Translate всё же пропал после того, как Discord
обновился, запустите команду установки ещё раз: она чинит установку, не теряя
настроек.

## Как делаются сборки

Vencord запускает только те плагины, которые были в него собраны, поэтому вы
скачиваете Vencord с AI Translate внутри. Руками их никто не собирает: робот на
GitHub проверяет каждый час, и как только у Vencord или AI Translate появляется
новая версия, он собирает их вместе из их же исходников и публикует результат
на [builds.zolatau.com](https://builds.zolatau.com/), где указаны те исходники,
из которых собрана каждая сборка.

## Удаление

Запустите ту же команду, что и для установки, и выберите **Remove**. Она снимает
подключение с Discord, и Discord становится ровно таким, каким был, а потом
спрашивает, удалить ли скачанные файлы. Закройте Discord полностью и запустите
снова.

Ключи API и настройки хранятся вместе с настройками Vencord, а не в скачанных
файлах, так что они останутся, если вы решите поставить плагин снова.

## Уже собираете Vencord сами

Из папки с Vencord склонируйте этот репозиторий как userplugin и пересоберите:

```
git clone https://github.com/mozumidesu/ai-translate src/userplugins/aiTranslate
pnpm build
```

Обе строки одинаковы на Windows, macOS и Linux, а `git clone` сам создаст
`src/userplugins`, если его ещё нет. После этого перезапустите Discord. С
Equicord работает так же. Собранная так копия сама с GitHub не обновляется:
делайте `git pull` и собирайте заново.
