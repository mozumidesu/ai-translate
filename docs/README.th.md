# AI Translate

ปลั๊กอินสำหรับ Discord ที่แปลข้อความของคุณด้วยโมเดล AI ที่คุณเลือก และแปลโดยไม่ทำให้วิธีเขียนของคุณเรียบไปหมด

ข้อความที่คุณส่งจะถูกแปลก่อนส่งออก แยกตามแต่ละแชท ส่วนข้อความที่คุณได้รับจะแปลเมื่อคุณสั่ง จากเมนูคลิกขวา

## ทำไมต้องมีตัวแปลอีกตัว

การแปลด้วยเครื่องถูกสร้างมาเพื่องานเขียนเป็นเรื่องเป็นราว แต่การแชทไม่ใช่แบบนั้น มันเป็นตัวพิมพ์เล็ก พูดค้างไว้ครึ่งทาง อยู่ได้ด้วยคาโอโมจิ และการไม่ใส่จุดก็กำลังสื่อบางอย่าง ตัวแปลส่วนใหญ่เก็บกวาดสิ่งเหล่านี้ไปอย่างเงียบ ๆ และสิ่งที่ไปถึงอีกฝั่งก็อ่านเหมือนจดหมายแบบฟอร์มที่คนอื่นเขียน

ตัวนี้สร้างขึ้นเพื่อไม่ไปยุ่งกับมัน มันจะไม่เติมเครื่องหมายวรรคตอนที่คุณไม่ได้เขียน ไม่เปลี่ยนตัวพิมพ์เล็กที่คุณตั้งใจทิ้งไว้ให้เป็นตัวใหญ่ เก็บการขึ้นบรรทัดใหม่ไว้ตรงที่คุณวางไว้ และรู้ว่าอิโมติคอนคือหน้าคน ไม่ใช่คำที่ต้องแปล

## มันทำอะไรได้บ้าง

การแปลอัตโนมัติตั้งแยกตามแชท ดังนั้นมันจะทำงานเฉพาะในบทสนทนาที่คุณต้องการจริง ๆ คลิกซ้ายที่ปุ่มแปลในแถบพิมพ์เพื่อเปิดแผงควบคุม คลิกขวาเพื่อเปิดหรือปิดแชทปัจจุบัน

ข้อความที่ได้รับทุกข้อความแปลได้จากเมนูคลิกขวา และเมื่อแม้แต่คำแปลก็ยังไม่ช่วยให้เข้าใจ เพราะตัวย่อ คำที่ใช้กันแค่ในประเทศเดียว หรือมุกที่รู้กันแค่สองคน **AI Explain** ในเมนูเดียวกันจะบอกว่าเป็นภาษาอะไร ขยายตัวย่อออกมา และอธิบายว่าเขาหมายถึงอะไร

ข้อความล่าสุดไม่กี่ข้อความของบทสนทนาจะถูกส่งไปพร้อมกับทุกคำขอ คำว่า "ครับ" สั้น ๆ หรือ "วางไม่ได้" จึงไปถึงอย่างที่ตั้งใจ คุณยังปักหมุดคลังคำของตัวเองได้ด้วย ทั้งคำที่ห้ามแปล คำเฉพาะที่ผูกกับคำแปลตายตัว เพศทางไวยากรณ์ที่ใช้กับตัวคุณเอง และจะพูดกับอีกฝ่ายแบบสุภาพหรือไม่

ข้อความเดียวก็เก็บบางส่วนของตัวเองไว้ได้ ใส่คำหรือวลีไว้ระหว่างแบ็กสแลชสองตัว `\carpe diem\` แล้วมันจะออกไปตรงตามที่คุณพิมพ์ โดยไม่มีแบ็กสแลช ส่วนแบ็กสแลชที่ต้นบรรทัดจะเก็บทั้งบรรทัดนั้นไว้ โค้ดในเครื่องหมายแบ็กทิกจะไม่ถูกแปลเลย

ใต้ข้อความที่คุณส่งไปแล้วสามารถเก็บต้นฉบับไว้ได้ โดยเห็นเฉพาะคุณคนเดียว เพื่อให้เห็นว่าสิ่งที่ส่งออกไปจริง ๆ คืออะไร ตัวนี้ปิดอยู่จนกว่าคุณจะเปิดเอง หน้าจอพูดได้ 16 ภาษา และจะตามภาษาของ Discord จนกว่าคุณจะเลือกเป็นอย่างอื่น

## ผู้ให้บริการ

คีย์ API คุณนำมาเอง และมันยังเป็นของคุณ ปลั๊กอินนี้ไม่มีเซิร์ฟเวอร์ของตัวเองและไม่เคยเห็นคีย์ของใคร

| ผู้ให้บริการ | โควตาฟรี |
|---|---|
| Groq | มี |
| Google Gemini | มี |
| Z.ai GLM | มี และเข้าถึงได้ในที่ที่อีกสองรายถูกปิดกั้น |
| Anthropic Claude | ไม่มี |
| API ใดก็ได้ที่เข้ากันได้กับ OpenAI | แล้วแต่ผู้ให้บริการ |

ตั้งผู้ให้บริการรายที่สองเป็นตัวสำรองได้ เมื่อรายแรกแน่น โควตาหมด หรือปฏิเสธคำขอ คำแปลจะไปทางอีกรายอย่างเงียบ ๆ โดยไม่มารบกวนคุณ

คำขอถูกส่งจากโพรเซสเบื้องหลังของ Discord คีย์ของคุณจึงไม่เคยเข้าไปอยู่ในส่วนของ Discord ที่หน้าเว็บเอื้อมถึง

## การติดตั้ง

AI Translate ทำงานอยู่ใน Vencord ซึ่งเป็นม็อดที่รู้จักกันดีของแอป Discord คำสั่งเดียวจะดาวน์โหลด Vencord ที่มี AI Translate อยู่ข้างในแล้ว ราวหนึ่งเมกะไบต์ และเชื่อมเข้ากับ Discord เครื่องของคุณไม่ต้องคอมไพล์อะไร และไม่ต้องติดตั้งอย่างอื่นเพิ่ม ใช้ได้กับ Discord ปกติ PTB และ Canary บน Windows, macOS และ Linux

**Windows.** เปิด PowerShell (เมนู Start แล้วพิมพ์ "PowerShell") แล้ววาง:

```
irm https://builds.zolatau.com/install.ps1 | iex
```

**macOS และ Linux.** เปิด Terminal แล้ววาง:

```
sh -c "$(curl -fsSL https://builds.zolatau.com/install.sh)"
```

ใช้ปุ่มลูกศรเลือก **Install or update** แล้วกด Enter เมื่อมันถามว่าจะเชื่อม Discord ตัวไหน ก็เลือกตัวที่คุณใช้ด้วยวิธีเดียวกัน บน Windows คำสั่งจะปิด Discord ให้เองก่อนเชื่อม บน Linux มันอาจขอรหัสผ่านของคุณ เพราะปกติ Discord อยู่ในที่ที่มีเพียงผู้ดูแลระบบเขียนได้ จากนั้นปิด Discord ให้สนิท รวมถึงจากไอคอนในถาดระบบ แล้วเปิดใหม่

บนระบบ Linux แบบอะตอมมิกอย่าง Bazzite, Silverblue, Kinoite หรือ SteamOS คำสั่งเดียวกันก็ใช้ได้ มันไม่ติดตั้งอะไรลงในระบบ ทุกอย่างไปอยู่ใน `~/.aiTranslate` ตัว Discord เองควรเป็นรุ่น Flatpak แล้วตัวติดตั้งจะให้สิทธิ์ Flatpak นั้นเข้าถึงไฟล์เหล่านี้เอง ส่วน Discord ที่ฝังอยู่ในอิมเมจระบบผ่าน `rpm-ostree` มักเชื่อมไม่ได้ เพราะโฟลเดอร์ระบบที่นั่นอ่านได้อย่างเดียว ให้ติดตั้งรุ่น Flatpak แทน

AI Translate เปิดใช้งานอยู่แล้ว เปิด **การตั้งค่า → Vencord → Plugins → AI Translate** เลือกผู้ให้บริการ แล้ววางคีย์ของคุณ

ทุกอย่างที่คำสั่งดาวน์โหลดมาอยู่ในโฟลเดอร์ของมันเอง: `%LOCALAPPDATA%\aiTranslate` บน Windows และ `~/.aiTranslate` บน macOS และ Linux การเชื่อม Discord หมายถึงการเปลี่ยนไฟล์เริ่มทำงานของมันเป็นไฟล์เล็ก ๆ ที่โหลด Vencord ก่อนแล้วจึงโหลด Discord เหมือนเดิมทุกประการ บัญชี การตั้งค่า และข้อความของคุณไม่ถูกแตะต้อง

## การอัปเดต

คุณไม่ต้องทำอะไรเลย AI Translate จะหาเวอร์ชันใหม่เองทุก 2 วัน ดาวน์โหลดในเบื้องหลัง แล้วแสดงการแจ้งเตือน กดที่การแจ้งเตือนนั้น Discord จะเริ่มใหม่พร้อมเวอร์ชันใหม่ ถ้าคุณไม่สนใจ การอัปเดตก็จะมีผลเองในครั้งถัดไปที่เปิด Discord ปุ่ม **ตรวจหาการอัปเดต** ที่ด้านล่างของการตั้งค่าปลั๊กอินทำแบบเดียวกันทันที

ทุกเวอร์ชันใหม่มี Vencord ล่าสุดมาด้วย การแก้ไขของ Vencord เองจึงมาทางเดียวกัน บน Windows และ Linux การเชื่อมยังอยู่รอดผ่านการอัปเดตของ Discord เองด้วย ถ้า AI Translate หายไปหลัง Discord อัปเดตตัวเอง ให้รันคำสั่งติดตั้งอีกครั้ง มันจะซ่อมการติดตั้งโดยไม่ทำให้การตั้งค่าของคุณหาย

## บิลด์ถูกสร้างขึ้นอย่างไร

Vencord รันเฉพาะปลั๊กอินที่ถูกคอมไพล์เข้าไปข้างในเท่านั้น สิ่งที่คุณดาวน์โหลดจึงเป็น Vencord ที่มี AI Translate อยู่ข้างใน ไม่มีใครสร้างด้วยมือ หุ่นยนต์บน GitHub ตรวจทุกชั่วโมง และทุกครั้งที่ Vencord หรือ AI Translate มีเวอร์ชันใหม่ มันจะคอมไพล์ทั้งสองอย่างเข้าด้วยกันจากซอร์สของแต่ละฝ่าย แล้วเผยแพร่ผลลัพธ์ที่ [builds.zolatau.com](https://builds.zolatau.com/) ซึ่งระบุซอร์สที่ใช้สร้างแต่ละบิลด์ไว้อย่างแม่นยำ

## การถอนการติดตั้ง

รันคำสั่งเดียวกับตอนติดตั้ง แล้วเลือก **Remove** มันจะถอดการเชื่อมออกจาก Discord ทำให้ Discord กลับไปเป็นเหมือนเดิมทุกประการ จากนั้นจะถามว่าจะลบไฟล์ที่ดาวน์โหลดมาด้วยหรือไม่ ปิด Discord ให้สนิทแล้วเปิดใหม่

คีย์ API และการตั้งค่าของคุณถูกเก็บไว้กับการตั้งค่าของ Vencord ไม่ใช่ในไฟล์ที่ดาวน์โหลดมา ดังนั้นมันยังอยู่ถ้าวันหนึ่งคุณติดตั้งใหม่

## ถ้าคุณบิลด์ Vencord เองอยู่แล้ว

จากโฟลเดอร์ Vencord ของคุณ ให้โคลนรีโพนี้เข้าไปเป็น userplugin แล้วบิลด์ใหม่:

```
git clone https://github.com/mozumidesu/ai-translate src/userplugins/aiTranslate
pnpm build
```

ทั้งสองบรรทัดเหมือนกันบน Windows, macOS และ Linux และถ้ายังไม่มี `src/userplugins` คำสั่ง `git clone` จะสร้างให้เอง จากนั้นเริ่ม Discord ใหม่ กับ Equicord ก็ทำแบบเดียวกัน สำเนาที่บิลด์แบบนี้จะไม่อัปเดตตัวเองจาก GitHub ให้ `git pull` แล้วบิลด์ใหม่
