# AI Translate

Плагін для Discord, який перекладає ваші повідомлення вибраною вами моделлю ШІ
і не причісує те, як ви пишете.

Ваші повідомлення перекладаються перед надсиланням, окремо в кожному чаті.
Вхідні перекладаються тоді, коли ви попросите, через меню за правим кліком.

## Навіщо ще один перекладач

Машинний переклад зроблено для прози. Листування не проза. Воно йде малими
літерами й недоказаними фразами, тримається на каомодзі, і відсутність крапки в
ньому щось означає. Більшість перекладачів тихо все це причісує, і на тому боці
виходить бланк, написаний кимось іншим.

Цей зроблено навколо того, щоб нічого не чіпати. Він не поставить крапку, якої
ви не ставили, не зробить великою літеру, яку ви лишили малою, збереже розриви
рядків там, де ви їх поставили, і знає, що смайлик це обличчя, а не слово, яке
треба перекласти.

## Що він уміє

Автопереклад вмикається окремо для кожного чату, тож він працює тільки там, де
справді потрібен. Лівий клік по кнопці перекладача в полі вводу відкриває
панель, правий вмикає або вимикає поточний чат.

Будь-яке вхідне повідомлення можна перекласти через меню за правим кліком. Коли
й переклад не допомагає, через скорочення, слівце, яке вживають в одній країні,
або жарт, зрозумілий двом, **AI Explain** у тому самому меню називає мову,
розшифровує скорочення й пояснює, що малося на увазі.

Разом із запитом ідуть кілька останніх повідомлень розмови, тому коротке «так»
або «не вставляється» доходить так, як задумано. Можна закріпити і свій
словник: слова, які не можна перекладати, терміни з одним сталим перекладом,
свій граматичний рід і те, на «ти» чи на «ви» звертатися до співрозмовника.

Окреме повідомлення теж може зберегти частину себе. Поставте слово чи фразу між
двома зворотними скісними рисками, `\carpe diem\`, і вона піде рівно так, як ви
її набрали, без самих рисок; зворотна риска на початку рядка лишає як є весь
рядок. Код у зворотних лапках не перекладається ніколи.

Під вашими надісланими повідомленнями може лишатися оригінал, видимий лише вам,
щоб ви бачили, що пішло насправді; це вимкнено, доки ви самі не ввімкнете.
Інтерфейс говорить 16 мовами і йде за мовою Discord, доки ви не виберете іншу.

## Провайдери

Ключ API ви приносите свій, і він лишається вашим. Плагін не має власного
сервера і ніколи не бачить чужих ключів.

| Провайдер | Безкоштовний тариф |
|---|---|
| Groq | є |
| Google Gemini | є |
| Z.ai GLM | є, і працює там, де два попередні заблоковані |
| Anthropic Claude | немає |
| Будь-який API, сумісний з OpenAI | залежить від провайдера |

Другим можна призначити запасного провайдера. Коли перший перевантажений,
вичерпав ліміт або відмовив, переклад мовчки йде через іншого.

Запити йдуть із фонового процесу Discord, тому ключ не потрапляє в ту частину
Discord, до якої може дотягнутися вебсторінка.

## Встановлення

AI Translate працює всередині Vencord, відомого мода для застосунку Discord.
Одна команда завантажує Vencord, у який AI Translate уже вбудовано, це близько
мегабайта, і під'єднує його до Discord. На вашому комп'ютері нічого не
збирається і нічого більше ставити не потрібно. Працює зі звичайним Discord,
PTB і Canary на Windows, macOS та Linux.

**Windows.** Відкрийте PowerShell (меню «Пуск», наберіть «PowerShell») і
вставте:

```
irm https://builds.zolatau.com/install.ps1 | iex
```

**macOS і Linux.** Відкрийте термінал і вставте:

```
sh -c "$(curl -fsSL https://builds.zolatau.com/install.sh)"
```

Стрілками виберіть **Install or update** і натисніть Enter. Коли спитає, який
Discord під'єднати, виберіть так само той, яким користуєтеся. На Windows
команда сама закриває Discord перед під'єднанням. На Linux може знадобитися
пароль: зазвичай Discord лежить там, куди може писати тільки адміністратор.
Потім закрийте Discord повністю, зокрема з трея, і запустіть знову.

На атомарних системах Linux, таких як Bazzite, Silverblue, Kinoite чи SteamOS,
працює та сама команда: у систему вона нічого не ставить, усе йде в
`~/.aiTranslate`. Сам Discord має бути з Flatpak, тоді встановлювач сам видасть
цьому Flatpak доступ до цих файлів. Discord, вшитий в образ системи через
`rpm-ostree`, під'єднати зазвичай не вийде: системні теки там лише для
читання, поставте версію з Flatpak.

AI Translate уже ввімкнено. Відкрийте **Налаштування → Vencord → Plugins →
AI Translate**, виберіть провайдера і вставте свій ключ.

Усе, що завантажує команда, лежить в окремій теці: `%LOCALAPPDATA%\aiTranslate`
на Windows і `~/.aiTranslate` на macOS та Linux. Під'єднання до Discord означає,
що його стартовий файл змінюється на маленький, який спершу завантажує Vencord,
а потім Discord рівно як раніше; вашого облікового запису, налаштувань і
повідомлень це не торкається.

## Оновлення

Робити нічого не потрібно. AI Translate сам раз на 2 дні шукає нову версію,
завантажує її у фоні й показує сповіщення; натисніть на нього, і Discord
перезапуститься вже з новою версією. Якщо не натискати, оновлення просто
застосується при наступному запуску Discord. **Перевірити оновлення** внизу
налаштувань плагіна робить те саме одразу.

Кожна нова версія несе й свіжий Vencord, тож його власні виправлення приходять
тим самим шляхом. На Windows і Linux під'єднання переживає й оновлення самого
Discord. Якщо AI Translate усе ж зник після того, як Discord оновився, запустіть
команду встановлення ще раз: вона лагодить встановлення, не втрачаючи
налаштувань.

## Як робляться збірки

Vencord запускає лише ті плагіни, які були в нього зібрані, тому ви
завантажуєте Vencord з AI Translate усередині. Руками їх ніхто не збирає: робот
на GitHub перевіряє щогодини, і щойно у Vencord чи AI Translate з'являється
нова версія, він збирає їх разом з їхніх же джерел і публікує результат на
[builds.zolatau.com](https://builds.zolatau.com/), де вказані ті джерела, з
яких зібрана кожна збірка.

## Видалення

Запустіть ту саму команду, що й для встановлення, і виберіть **Remove**. Вона
знімає під'єднання з Discord, і Discord стає рівно таким, яким був, а потім
питає, чи видалити завантажені файли. Закрийте Discord повністю і запустіть
знову.

Ключі API та налаштування зберігаються разом з налаштуваннями Vencord, а не в
завантажених файлах, тож вони лишаться, якщо ви вирішите поставити плагін знову.

## Уже збираєте Vencord самі

З теки з Vencord склонуйте цей репозиторій як userplugin і перезберіть:

```
git clone https://github.com/mozumidesu/ai-translate src/userplugins/aiTranslate
pnpm build
```

Обидва рядки однакові на Windows, macOS і Linux, а `git clone` сам створить
`src/userplugins`, якщо його ще немає. Після цього перезапустіть Discord. З
Equicord працює так само. Зібрана так копія сама з GitHub не оновлюється:
робіть `git pull` і збирайте заново.
